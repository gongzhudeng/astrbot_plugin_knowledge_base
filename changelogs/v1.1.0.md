# v1.1.0

- Add optional hybrid retrieval with a local BM25 index and stable dense+sparse RRF fusion.
- Keep legacy dense search as the fallback for old collections, missing or broken sparse indexes, and rerank failures.
- Preserve Spark and BusySchedule retrieval contracts, including `req.prompt`, `retrieval_query`, and accumulated `background_retrieval_results`.
- Keep automatic knowledge injection in temporary `TextPart` content blocks so retrieved text is not persisted in conversation history.
- Add duplicate and size limits for injected context, plus a warning when AstrBot's built-in knowledge base is enabled at the same time.
- Add Markdown-aware ingestion chunks with section paths, chunk indexes, source metadata, and content hashes.
- Add regression coverage for protocol compatibility, fallback behavior, hybrid ranking, and structured chunking.
